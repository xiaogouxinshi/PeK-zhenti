# 北京定向选调 · 面试真题全真模拟（2021—2026届）

一个**单文件、离线可用**的北京定向选调面试刷题网页，专注「读题版」全真模拟。

## 特性

- **60 道真题**：覆盖 2021—2026 届北京定向选调面试真题

- **双维度浏览**：按题型（综合分析 / 管理组织 / 应急应变）或按年份切换视图，支持关键词搜索

- **AI 朗读读题**：每道题内嵌语音朗读，模拟考官读题场景（音频已 base64 内嵌，无需联网）

- **单题练习**：语速调节、答题计时、重点标记、上一题/下一题快捷切换

- **整场模拟**：20:00 倒计时、连续读题、时间到提醒，还原真实考场节奏

- **学习进度**：未练/已练/已掌握三态标记，本地自动保存

## 使用

- **在线**：开启 GitHub Pages 后直接访问（见下方部署）

- **本地**：下载 `index.html`，双击用浏览器打开即可，无需任何依赖

## 部署到 GitHub Pages

1. 将本目录全部文件（含隐藏的 `.nojekyll`）上传到仓库根目录
2. 仓库 **Settings → Pages → Source** 选择 `main` 分支 `/ (root)`，保存
3. 稍等 1\~2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`

> `.nojekyll` 用于跳过 Jekyll 构建——本页面含大段 base64 音频数据，必须跳过处理才能正常发布。

## 说明

- 题目整理自《2027 届北京定向选调面试真题详细讲解》（余小峰编著），仅供个人备考学习使用

- 语音由 TTS 合成预生成，非真人朗读
